# NIGHT74 kickoff (what GG does to start the night)

1. **Start right after a usage reset if you can.** A night begun in a fresh window ran about 2:20 of agent work before a stop (NIGHT66-68;
   memory night-usage-window). Claude Code continues through a usage limit by itself, but not if the PC sleeps for 30 minutes or more:
   set the PC to never sleep on AC for the night.
2. Open a **fresh** Claude Code session in C:\Users\gaige\dev\SKYGRIND-unity, with the Unity Editor open on the project and nothing else
   heavy running. (The forge session is too full to run a night.)
3. Effort: your settings run xhigh (`effortLevel` in ~/.claude/settings.json); NIGHT71 and NIGHT72 ran on it. Keep it; never change it
   mid-run.
4. Paste the goal (Research/2026-10-27-forge74/GOAL.txt, end condition first), then send:
   `begin: read NIGHT74.md in full and start section 4 now`.
5. The night ends on its own with the final message `NIGHT74 COMPLETE` (between 7:30 and 8:00 after the start). Then run `/goal clear`.

What you get: **Builds/n74-play** (the game with every change that passed turned ON: your NIGHT71 rooms back, the rebuilt rooms that
passed, bosses whose cyan means "shoot here") and **PLAY74.md** (one line per change, where to see it, how to switch it off, keep / drop
boxes). To compare: `SKYGRIND.exe -skygrindRows72 kiln67:0` (a level's old rooms), `-skygrindRows72 weak74:0` (a row off).
