# room71 (L1, design.n71.room71; play-build-only row, OFF in the repo) - code e87b20fb5, switch fix 1a54e866b
**Visible change (one sentence):** in the level select, left / right on a level picks "START: 3.3 CASTING FLOOR (kb3)" on the select's own hint line, and the run then begins in that room (DOORFREE on, so unranked).
**How:** UiRoom71.cs reads the level file's campaign rooms (links left out). Room71Runner holds DOORFREE through the player's own input path (N29Fixes.ForceDoorFreeHold, 3 s, as DoorFree29Check does) until the sim reads it on. It then respawns at the room's spawn, and the campaign enters the room by its zone. Nothing runs inside a sim step. The menu's look is unchanged: same label, font, size and colour, only its words.
**Off:** the row off, -skygrindNoRoom71, -skygrindOff71: left / right do nothing, the hint shows its own words, -skygrindStartRoom is ignored (said in the log).
**Proof (the lead; a build with n71.room71 ON, kiln in it):** `Builds/<tag>/SKYGRIND.exe -skygrindMap n67-kiln -skygrindStartRoom kb3 -logFile Logs/player/n71-room71-on.log` (use n52-kiln if kiln67 is not in the build). Close it by PID after ~15 s.
GREEN: `[room71] start room kb3 ... DOORFREE on after ~3.0 s, respawned at its spawn`, then `[room71] room entered kb3 '...' <5 s after the run began`. RED: the same plus `-skygrindNoRoom71` gives `[room71] -skygrindStartRoom kb3 ignored: -skygrindNoRoom71` and no "room entered".
**Found while building (1a54e866b):** every `-skygrindNo<Row>71` switch counted as an automation arg (N29Fixes.IsAutomationArg). That skips the CAMPAIGN default, and the level select's reload then cannot leave the default map. So GG's A / B flags (e.g. -skygrindNoCyan71) would have stranded him. They now boot like a player's game, as -skygrindOff46+ do. This is read from the code and not checked in a Player. A Player check: `SKYGRIND.exe -skygrindNoCyan71`, TITLE > PLAY > a level: the level loads.
**Limits:** left / right on the keyboard could also move the EventSystem's focus sideways (not checked). The hint line is 900 px wide, and a long room name may run past it (not checked).
**EditMode:** N71RoomTests (5 tests, incl. the switch rule; not run by me). dn-check 0 errors.
