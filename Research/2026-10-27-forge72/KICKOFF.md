# NIGHT72 kickoff (what GG does to start the night)

1. **Start right after a usage reset if you can.** A night begun in a fresh window ran about 2:20 of agent work before a stop
   (NIGHT66-68; memory night-usage-window). NIGHT71 ran its full 8 hours without one.
2. Open a **fresh** Claude Code session in C:\Users\gaige\dev\SKYGRIND-unity, with the Unity Editor open on the project and nothing
   else heavy running. A forge session is too full to run a night (APEX S9).
3. Effort: your settings run xhigh (`effortLevel` in ~/.claude/settings.json), and NIGHT71 finished its 8 hours on it, so keep it.
   Anthropic's page says medium (the default) matches Opus 5 at high, and to keep xhigh for measured gains: lower is your call
   (DECIDE72). Never change it mid-run (it invalidates the cache).
4. Paste the goal (Research/2026-10-27-forge72/GOAL.txt, 763 characters, end condition first), then send:
   `begin: read NIGHT72.md in full and start section 4 now`.
5. The night ends on its own with the final message `NIGHT72 COMPLETE` (about 7:00-7:30 after the start). Then run `/goal clear`.

What you get: **Builds/n72-play** (the game itself, with every change that passed turned ON) and **PLAY72.md** (one line per change, where
to see it, how to switch it off, keep / drop boxes). To compare any change, start the game with its off switch (for example
`SKYGRIND.exe -skygrindNoBody72`, or `-skygrindRows72 colours63:0`).
