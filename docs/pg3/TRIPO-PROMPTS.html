SKYGRIND: model prompts (ChatGPT image → Tripo 3D)

Weapons and enemy types (no bosses). Make a reference picture in ChatGPT, then turn it into a model with Tripo's Image to 3D. Same blocky, flat-shaded look as the game now, just cooler. 2026-10-28.

How to use these

  1. ChatGPT: copy a model's prompt (each one is complete) into ChatGPT and generate the image. Check it: the whole object is in frame, the background is transparent (a checkerboard in the preview), there's no floor or shadow, and there's one object only. If the background isn't transparent, reply "remove the background, transparent PNG". Download the PNG.
  2. More views (optional, better shape): in the same chat, paste the "same object from the side / back" prompt below, then use Tripo's multi-view mode with front, side and back.
  3. Tripo: Image to 3D, upload the PNG (or the views), and generate with textures on and a moderate face count. It should stay low-poly.
  4. Generate the moving parts on their own (KESTREL cylinder and hammer, THUNDERCLAP pump). The body prompts leave them out, so the game can keep spinning the cylinder and sliding the pump.
  5. Export FBX in metres, named exactly as the file line says. Put the files in Inbox/tripo/, and I'll check them, fit them and turn the tripo74 row on.
  6. Facing: guns point their muzzle forward (+Z in Unity); enemies face forward with their feet at the bottom.

Plug-in status. ready the code already loads this model. small code change the model works once I add a hook (part models, gauntlet, torch). The current hook hides the code-built cylinder, hammer and pump when a gun model loads, so their animations stop. Part models fix that.

Follow-up for more views (paste in the same chat after the first image)
Now draw the exact same object again: identical design, proportions, parts and colours, same style and lighting, same scale. Show it from the exact side (a flat profile view) as one image, then from the exact back as a second image. Each image: the whole object fully in frame and centred, transparent background (PNG with alpha), no floor, no shadow, no text.
